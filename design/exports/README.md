# 设计导出

**语言：[中文](README.md) | [English](README.en.md)**

用于保存评审和报告的稳定导出件，例如：

- `v01/`：首次团队评审
- `v02/`：用户测试版本
- `final/`：最终提交截图或录屏

命名建议：`页面名_状态_YYYY-MM-DD.png`，确保报告引用时不会指向会变化的 Figma 页面。
