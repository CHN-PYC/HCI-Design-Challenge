# Design Exports

**Language: [中文](README.md) | English**

Store stable exports for reviews and reports, for example:

- `v01/`: first team review
- `v02/`: user-testing version
- `final/`: final submission screenshots or screen recording

Naming recommendation: `screen-name_state_YYYY-MM-DD.png`, so report links do not point to a Figma page that may change.
