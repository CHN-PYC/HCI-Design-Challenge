# 评估与迭代

> 源文档尚未记录可用性测试或评估计划。本目录预留，不代表相关活动已经开始。

## 待验证的核心问题

后续原型评估应优先验证：

1. 用户是否理解主动建议的来源和目的。
2. 建议的时机、内容和频率是否真正有帮助。
3. 用户能否轻松接受、推迟、拒绝或关闭建议。
4. 用户是否清楚哪些数据被使用，并能控制权限。
5. 界面是否能促成健康行为，而不是增加新的干扰。
6. 来自不同文化/饮食背景的用户是否感到被正确理解。

## 建议的评估产物

- `test-plan.md`：目标、参与者、任务、伦理与记录方式。
- `sessions/`：去标识化后的测试记录。
- `findings.md`：主题、证据、严重度和设计影响。
- `iteration-log.md`：问题、改动、复测结果。

## 开始条件

- [ ] 已有可点击且核心流程完整的原型。
- [ ] 研究问题与评价指标已确定。
- [ ] 参与同意和数据保护方式已确认。
- [ ] 至少一名成员负责主持，另一名负责记录。
