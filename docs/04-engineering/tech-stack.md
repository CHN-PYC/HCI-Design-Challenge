## 选择标准

1. 团队能在课程时间内完成并维护。
2. 能验证核心交互，而不是为了技术演示牺牲设计质量。
3. 支持必要平台能力（如通知），且有明确的权限处理。
4. 能最小化健康数据收集并支持删除/退出。
5. 外部 API 失败时仍有可展示的降级体验。
