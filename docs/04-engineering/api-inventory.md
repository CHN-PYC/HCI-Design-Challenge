# API 与数据能力候选清单

> 所有状态均为“候选/待验证”。用户研究确认需求前，不应把这些能力视为 MVP 的必备功能。

| ID | 能力 | 数据/依赖 | 用途 | 主要限制 | 原型中的处理 | 状态 |
| --- | --- | --- | --- | --- | --- | --- |
| API-01 | 位置 | 设备 GPS/定位服务 | 推断大致位置、附近地点、国家或地区 | 后台定位受限；需要权限；隐私敏感 | 可用静态位置或地图截图模拟 | 待验证 |
| API-02 | 天气 | Open-Meteo 或同类服务 | 天气/预报支持户外活动或食品建议 | 服务可用性、地区覆盖、频率限制 | 可用固定 JSON 样例 | 待验证 |
| API-03 | 本地通知 | iOS/Android 通知系统 | 无需打开 App 的主动建议 | 通知权限、后台执行、打扰风险 | 展示通知状态与设置 | 待验证 |
| API-04 | 用户偏好 | 本地设置/数据库 | 健康目标、饮食偏好、提醒设置 | 数据最小化、跨设备一致性、清除机制 | 使用表单或预设选项模拟 | 待验证 |
| API-05 | 食谱数据 | TheMealDB 或同类 API | 结合菜系、预算和用餐时间推荐食谱 | API 条款、费用、速率限制、营养/过敏信息不足 | 用固定食谱数据展示推荐逻辑 | 待验证 |
| API-06 | 拍照识别 | 设备相机/图像识别服务 | 识别食物并估算热量（候选） | 第一轮原型不实现；准确性、隐私和伦理风险高 | 只展示入口和模拟结果 | 待调研 |

## 每个 API 的核实字段

- 官方文档链接与访问日期
- 认证方式、费用与速率限制
- 数据字段与覆盖地区
- 是否包含健康相关错误或不准确性
- 隐私条款与数据保留方式
- 失败/离线时的降级体验
