## 会议记录模板

新会议记录建议包含：

- 日期、参与者、主持/记录人
- 议程与讨论要点
- 明确决策，以及对应证据
- 行动项：任务、负责人、截止日期、验收标准
- 未决问题与下次会议时间
- 相关链接（问卷、竞品证据、Figma、代码 PR）
