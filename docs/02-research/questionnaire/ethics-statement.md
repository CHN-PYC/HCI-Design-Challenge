## 数据收集与处理

| 项目 | 规则 |
| --- | --- |
| 收集方式 | 线下匿名访谈和记录 |
| 收集内容 | 年龄分组、文化背景（选答）、饮食安排、App 使用经历、功能需求、匿名开放反馈 |
| 不主动收集 | 姓名、联系方式、账号、照片、精确位置或其他直接识别信息；如访谈需要语音记录，匿名转录后删除原始音频 |
| 原始记录处理 | 完成匿名整理后删除原始笔记；开放题中的偶然可识别信息在分析前删改 |
| 最终保留数据 | 仅保留无法单独识别参与者的匿名汇总数据 |
| 使用目的 | 课程用户研究与设计决策、报告和展示 |
| 存储与访问 | 仅保存在研究团队受控且不公开的课程资料中；原始记录不得提交到公开仓库 |
| 保存期限 | 匿名汇总数据保留至课程考核结束；原始记录在匿名化完成后删除 |
| 退出与删除 | 参与者可随时停止；数据匿名汇总后无法定位个人记录，因此无法单独删除其回答 |
| 咨询/投诉渠道 | Russell Beale，r.beale@bham.ac.uk；如课程另有独立渠道，以课程规定为准 |

## 设计约束

- 当前问卷顶部说明较简略；正式发布版应先展示完整伦理声明，再显示研究题目。
- 联系方式应与匿名问卷数据分开收集。
- 不要求参与者提供不必要的健康、种族/族裔或其他敏感信息。
- 对“不愿回答”提供明确选项。
- 开放题可能意外包含可识别信息，转录或汇总时必须复核并删改。
- 不对小样本文化/族裔分组做单独披露，以降低推断式再识别风险。
- “无个人信息泄露风险”不应被写成绝对保证；文档使用“降低可识别信息风险”的表述。
