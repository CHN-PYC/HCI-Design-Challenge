# 问卷题目草案

> **已被取代：** 当前正式候选为 [V3 参与者问卷](questionnaire-v3-participant.md)。本文件保留 V0 历史草案，不再作为发放依据。

> 状态：**待定稿**。本文件把源文档中的研究问题整理成问卷结构，不代表最终文案。发布前必须补齐伦理声明、量表/选项和逻辑跳转，并完成预测试。

## A. 伦理与同意

1. 在问卷顶部展示伦理声明，并让参与者确认已阅读。
2. 说明研究目的、参与是否自愿、预计耗时、数据用途、匿名化方式、退出方式与联系人。

详见 [ethics-statement.md](ethics-statement.md)。

## B. 背景信息

1. 年龄范围：待与团队确认分组方式。
2. 当前身份：大学生 / 其他（用于筛除或分层）。
3. 学习或工作领域：待确认是否需要。
4. 种族/文化背景：使用可多选、可自填、可选择不回答的选项；用于理解饮食标准和习惯差异。
5. 饮食偏好或限制：如素食、过敏、宗教/文化限制等；选择“不适用”或“不愿回答”。

## C. 当前健康习惯

### 饮食

1. 典型一天中，你的饮食安排大致如何？
2. 你通常在哪里、和谁一起、什么时间用餐？
3. 你每周准备或烹饪食物的频率如何？
4. 哪些因素会帮助你吃得更健康？

### 体力活动

1. 你通常进行哪些体力活动？
2. 每周频率和时长如何？
3. 哪些情境会让你更容易保持或中断活动？

### 作息

1. 典型工作日的睡眠与起床时间是什么？
2. 学业、社交或手机使用是否影响你的作息？
3. 你目前最希望改善的作息问题是什么？

## D. 实际困难与现有应对方式

1. 在饮食方面，你遇到哪些实际困难？
2. 在体力活动方面，你遇到哪些实际困难？
3. 在作息方面，你遇到哪些实际困难？
4. 目前你如何解决这些困难？
5. 哪些解决方法有效？哪些没有效果？为什么？
6. 你希望获得什么样的支持，但这种支持目前还不存在？

## E. 现有健康 App 与替代方案

1. 你使用过哪些健康、饮食、运动或作息类 App？
2. 使用它们的原因是什么？后来又为什么继续或停止使用？
3. 这些 App 在哪些方面帮助你？
4. 这些 App 有哪些不足、打扰或不信任之处？
5. 除 App 外，你还使用哪些方式管理健康习惯？

## F. 对主动式建议的接受度

1. 你是否接受系统在未打开 App 时主动提供健康建议？
2. 哪些建议会有帮助？哪些会显得冒犯、打扰或无关？
3. 什么时机最适合接收建议？什么时机不适合？
4. 你希望多久收到一次建议？
5. 你希望如何控制建议（接受、推迟、关闭、设置免打扰等）？
6. 哪些数据你愿意提供？哪些不愿意？为什么？

## G. 通知偏好

1. 你是否希望 App 使用通知？
2. 你接受哪些通知类型：提醒、鼓励、数据摘要、建议、其他？
3. 你偏好哪些通知频率与时间段？
4. 你希望怎样管理免打扰和通知权限？

## H. 核心功能偏好

1. 如果只能保留一个核心功能，你最希望是什么？
2. 你希望 App 首页最显眼的功能是什么？
3. 对以下候选方向排序（仅在研究确认后纳入）：食谱推荐、食物识别、活动建议、作息支持、健康数据摘要。
4. 哪些功能目前看起来有吸引力但你不一定会长期使用？

## I. 开放结尾

1. 还有什么我们应该了解的健康习惯、困难或 App 体验？
2. 是否愿意参加后续访谈或原型测试？如是，请通过独立、符合伦理的渠道留下联系方式，不写入匿名问卷数据集。
