## 目标

了解首轮目标用户（大学生）的健康习惯、实际困难、现有解决方案、对主动式健康支持的接受度，以及最希望获得的功能支持。

## 必需模块

1. **伦理声明**：必须位于问卷顶端。
2. **基本信息与背景**：包含种族/文化背景筛选，用于理解饮食标准和生活习惯差异。
3. **当前健康习惯**：饮食（V3 已覆盖）；体力活动与作息（当前未覆盖，待范围确认）。
4. **实际困难与应对方式**：不仅问“做了什么”，也问“为什么难以维持”和“目前怎样处理”。
5. **现有健康 App 的不足**：使用习惯、满意与不满意、未被满足的需求。
6. **主动建议的接受度**：是否接受、何种时机、频率、隐私与用户控制。
7. **通知偏好**：是否需要通知、接受哪些类型、偏好如何控制。
8. **功能偏好**：最常用或最想用的核心功能，用于判断首页重点；菜谱推荐和识别仅为候选示例。
