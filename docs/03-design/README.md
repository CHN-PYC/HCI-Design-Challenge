## 当前阶段

已有 7 屏 Figma 设计归档，并完成配套的 [系统设计](../04-engineering/system-design.md) 与 [模块设计](../04-engineering/module-design.md)。设计语言和统一的页面框架可以从现有设计稿评审形成基线；具体功能仍需用户研究验证。

## 已记录的约束

- 第三次会议需要选择 App 设计语言和设计交互逻辑。
- 先让 ChatGPT 提供几种页面设计方案，由团队选定统一框架后再多人开发，避免风格分裂。
- Figma 原型必须支持按钮到页面的可点击跳转。
- 第一轮原型不要求真正实现数据导入、拍照识别等底层能力。
- 需要提前列出并说明现实可行的外部 API 依赖。
- 首轮只聚焦最重要的基础功能，后续通过第二轮调研补充。
