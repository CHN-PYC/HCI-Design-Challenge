# 项目定义

## 一句话定义

探索一款基于智能手机的主动式健康管理系统，帮助用户形成并维持更健康的日常习惯；第一阶段研究聚焦大学生，未来可扩展到其他人群。

## 设计原则（由现有研究问题推导）

1. **用户控制优先**：建议应可接受、推迟或拒绝；权限和通知可配置。
2. **情境相关**：不以重复提醒替代理解用户的实际时间、地点与任务压力。
3. **先验证再扩展**：先用问卷、访谈和竞品分析确认需求，再决定功能。
4. **隐私最小化**：健康与设备数据只收集设计验证真正需要的信息。
5. **原型与实现分离**：Figma 负责验证页面流与交互；外部 API 用于证明方案可落地，但不要求第一轮实现全部底层能力。
